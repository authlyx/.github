## Features

- **License & user authentication** - Validate users and licenses against your application with a single API call
- **Device locking** - Bind licenses to hardware identifiers including HWID, SID, motherboard and CPU IDs
- **App variables** - Store and retrieve remote configuration scoped to your application
- **Session management** - Track active sessions with full audit log support
- **Dashboard** - Manage users, licenses, and logs from a centralized web interface
